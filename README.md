# Ready for School (What to Wear) — a Home Screens plugin

One plan for the school day from the forecast (Open-Meteo, no key needed):

- **Put on** — what to wear leaving the house (right boots from the start if rain/snow comes later)
- **In the backpack** — only what's needed later: rain gear, cap & sunscreen, spare socks, water bottle
- a tip line (e.g. "Warmer after lunch — tuque and gloves can go in the backpack") and an hourly strip for the school day
- switches to tomorrow's plan in the evening

## Install

Home Screens editor → **Plugins** → **Install from URL…**:

```
https://github.com/tweetyboopdev2022-code/home-screens-what-to-wear/releases/download/v1.2.0/what-to-wear-1.2.0.tgz
```

## Build

```
npm install && npm test && npm run build
```
